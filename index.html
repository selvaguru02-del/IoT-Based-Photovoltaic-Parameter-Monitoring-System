Why this project exists

Solar panels degrade quietly

Dust, partial shading, loose wiring, and ageing cells all cut into a solar panel's output — and on a system checked only by occasional human inspection, that loss can go unnoticed for weeks. This project replaces manual spot-checks with continuous, automated monitoring.

A 5 W polycrystalline panel is instrumented with a resistive voltage-divider sensor and an ACS712 Hall-effect current sensor, alongside a DHT11 for ambient temperature/humidity and an LDR for light intensity. An Arduino Mega 2560 reads all four channels, hands the readings to a NodeMCU ESP8266 over serial, and the ESP8266 pushes them straight into a Firebase Realtime Database — viewable from any browser or an Android app, from anywhere.

Project objective

Monitor the output of a PV system — voltage, current, temperature, humidity and light intensity — using low-cost wireless sensors, and make that data available in real time via the cloud, so faults and performance drops can be caught early instead of during the next manual inspection.

Data pipeline

How a reading gets from panel to phone

01

Sense

The voltage and current sensors sit across and in-line with the panel; the DHT11 and LDR sit alongside it, reading ambient temperature, humidity and light.

02

Read & compute

The Arduino Mega samples all four analog/digital channels, converts raw ADC values into volts, amps, °C, % RH and lux, and computes instantaneous power (P = V × I).

03

Hand off over serial

Readings are formatted as strings and sent over a hardware serial line to the NodeMCU ESP8266.

04

Push to the cloud

The ESP8266 connects to Wi-Fi and writes each reading to a Firebase Realtime Database node using the Firebase Arduino library.

05

Monitor anywhere

The Firebase console — or a companion Android/iOS app — shows the live values, letting a technician spot a fault without visiting the panel.
